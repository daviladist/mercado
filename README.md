# D'Ávila Pedidos

App de pedidos de atacado do ATACADO D'ÁVILA (cliente, administrador, conferente, faturamento e vendedor).

- `index.html` — o app inteiro (sem dados reais e sem senhas no código).
- `vercel.json` — cabeçalhos de segurança e bloqueio de indexação no Google.
- `robots.txt` — pede para buscadores não indexarem.

## Regras deste repositório
- Repositório **privado**.
- **Nunca** colocar aqui backups (`.json`), planilhas ou PDFs com dados de clientes. O `.gitignore` já bloqueia esses arquivos.
- Senhas nunca vão no código. O administrador é criado no primeiro acesso.

## Publicação
Ligado à Vercel: cada atualização enviada para a branch `main` é publicada sozinha em 1 a 2 minutos.
